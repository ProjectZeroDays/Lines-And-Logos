## General Follow-Up Rules
- **Max 3 touches** per prospect per cycle. If no response after Email 3, move to "nurture" and re-engage next budget cycle.
- **Personalize the first line** — reference a specific recent event (new building, bond measure, campaign, hire) whenever possible.
- **Always offer a no-cost walkthrough** — it converts better than a call.
- **Track in CRM:** account, contact, date, touch #, response, next action, budget cycle month.
- **Never send the same template twice** to the same person — vary the angle each cycle.
