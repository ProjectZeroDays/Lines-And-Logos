## Objection Handling

| Objection | Response |
|---|---|
| "We already use Sports Floors." | "Sports Floors does excellent floor work. We handle the floor AND everything around it — walls, windows, signage, donor wall, parking lot — so you don't have to manage five vendors. Can we quote the wrap + signage portion Sports Floors doesn't do?" |
| "We need to bid this out." | "Understood. We can bid the floor portion competitively AND include the branding scope Sports Floors can't bid. You'll get one proposal covering both." |
| "Budget is tight." | "Our Gym Refresh starts at $8K. Or we can phase it — floor this summer, walls/signage next fiscal year. We can also structure around grant codes." |
| "We're too far for you." | (Only relevant vs. Finchum/GameDay.) "We're based in Memphis. You're closer to us than to Sevierville or Atlanta." |

## Win Themes
1. **One contract, one invoice, one point of contact** — reduces procurement overhead for districts.
2. **Summer install window** — we're local and available when floors need to be done (May–Aug).
3. **Capital-campaign ready** — donor walls + signage + branding for churches/private schools/YMCAs raising funds.
4. **Grant-friendly** — itemized scopes chargeable to specific grant codes (ESSER, bonds, capital campaigns).
5. **MWBE / woman-owned positioning** — if applicable, note for public procurement advantage (Sports Floors and Conrad are both woman-owned; verify your own status).
